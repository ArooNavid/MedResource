# یادداشت‌های اتمی

برنامهٔ وب AtomicNotes روی همین مخزن. خزانهٔ مارک‌داون، ورود PDF، جستجوی متن کامل، برچسب، پیوند `[[wikilink]]`، گراف، همگام‌سازی دوطرفه با Obsidian، یادداشت روزانه با تاریخ تهران، دفتر ماهانه، قالب با جای‌گذار تهران، پشتیبان و آمار کارکرد با نقش کاربر و مدیر.

## تصمیم‌های قفل‌شده

- حداکثر عمق درخت **۱۵** است.
- وضعیت نهایی ورود **Committed** است، نه Completed.
- تنظیمات با `Load()` و `Save()` همگام خوانده و نوشته می‌شود و مسیرش `SettingsFilePath` است.
- ساعت تهران همان قرارداد `ITehranClockService` است: منطقهٔ `Asia/Tehran` و در نبود آن اختلاف ثابت `+03:30`.
- زمان‌بند پشتیبان با `RestartAsync` و قفل شروع کار می‌کند تا دو حلقه همزمان نسازد.
- کاربر عادی فقط آمار خودش را می‌بیند. مدیر آمار همه را می‌بیند و مقایسه می‌کند. نقش از پایگاه‌داده خوانده می‌شود.
- اولین حسابی که ثبت می‌شود مدیر است.

## اجرا

```bash
export PATH="$HOME/.dotnet:$PATH"
export DOTNET_ROOT="$HOME/.dotnet"
dotnet test
dotnet run --project AtomicNotes.Web
```

سپس مرورگر را روی `http://localhost:5080` باز کنید.

پایگاه‌داده، خزانه و پشتیبان پیش‌فرض زیر پوشهٔ دادهٔ برنامه (`AtomicNotes`) ساخته می‌شوند. مسیرها از صفحهٔ تنظیمات عوض می‌شوند.
